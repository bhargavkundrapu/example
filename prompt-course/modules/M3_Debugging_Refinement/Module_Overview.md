# Module 3: Debugging & Refinement

> When AI gives bad output, fix it fast.

## What You'll Learn
This module teaches you to diagnose prompt failures, use the 3R Loop to fix them, score outputs on Fluency, Relevance, and Coherence, perform A/B testing, and build reusable templates.

## Why This Matters
Even great prompts sometimes fail. The difference between a beginner and an expert is knowing HOW to evaluate and fix a prompt quickly using numerical NLP metrics and systematic A/B testing.

## Lessons

| # | Lesson | What You'll Master |
|---|--------|--------------------|
| M3-L1 | Common Failure Types | Identify the 5 most common prompt failures |
| M3-L2 | 3R Loop Workflow | Master Request, Review, Refine |
| M3-L3 | Self-Critique Prompts | Make AI evaluate and fix its own output |
| M3-L4 | Evaluation Metrics & A/B Testing | Score prompts on Fluency, Relevance, Coherence & conduct A/B tests |
| M3-L5 | Reusable Prompt Templates | Build templates you use again and again |

## Key Framework
**3R Loop & F-R-C Evaluation** - Request, Review, Refine + Fluency, Relevance, and Coherence metrics.

## Time to Complete
50-75 minutes (5 lessons x 10-15 min each)

## Student Relevance
- Fix failed prompts during assignment crunch time
- Evaluate and A/B test prompt variants for projects
- Build a personal library of working templates
