# Module 7: Coding With AI

> Write better code faster. Debug smarter. Ship faster.

## What You'll Learn
This module teaches you to write clear code specifications, debug code systematically, refactor code to clean principles, construct programmatic prompt chains for LLM APIs, and plan system architecture with AI.

## Why This Matters
Using AI for coding isn't just asking "write me a website." It's giving precise specs, debugging with tracebacks, building multi-step API prompt chains, and designing software architecture.

## Lessons

| # | Lesson | What You'll Master |
|---|--------|--------------------|
| M7-L1 | Spec Prompts | Turn a vague idea into a clear coding specification |
| M7-L2 | Debug Prompts | Find and fix bugs using AI systematically |
| M7-L3 | Refactor Prompts | Clean up messy code with structured prompts |
| M7-L4 | LLM APIs, Automation & Prompt Chaining | Chain multi-step prompts for APIs and automated application pipelines |
| M7-L5 | System Design Prompts | Use AI to plan architecture and system design |

## Key Framework
**Spec-Debug-Refactor-Chain Pipeline** - The 4-step software development workflow for AI coding and API automation.

## Time to Complete
50-75 minutes (5 lessons x 10-15 min each)
