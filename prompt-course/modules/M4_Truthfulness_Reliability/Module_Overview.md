# Module 4: Truthfulness & Reliability

> Stop AI from making things up. Get factual, verified output.

## What You'll Learn
This module teaches you to stop AI hallucinations, force "don't guess" behavior, make AI cite sources, protect system prompts against Prompt Injection attacks, and use anti-hallucination checklists.

## Why This Matters
AI hallucination and prompt injection vulnerabilities can ruin project accuracy and security. Learning to restrict AI to verified sources and protect system instructions ensures reliable, secure AI responses.

## Lessons

| # | Lesson | What You'll Master |
|---|--------|--------------------|
| M4-L1 | "Don't Guess" Mode | Force AI to say "I don't know" instead of guessing |
| M4-L2 | Verification Prompts | Make AI cite sources and check its own facts |
| M4-L3 | Answer From Given Text Only | Restrict AI to only use information you provide |
| M4-L4 | Prompt Injection & Security Defense | Protect system prompts with boundary delimiters & prevent jailbreaks |
| M4-L5 | Anti-Hallucination Checklist | A 5-step checklist to catch false information |

## Key Framework
**Anti-Hallucination & Security Boundary System** - Restrict context boundaries and isolate untrusted user data to stop hallucinations and injection attacks.

## Time to Complete
50-75 minutes (5 lessons x 10-15 min each)
