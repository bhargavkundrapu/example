## SEC-04_WHAT_THIS_TOOL_DOES

Turn noise into routines: notes, quizzes, pacing. AI helps **structure**. You supply **truth**.

Tools here **accelerate scaffolding and critique**. They **never** certify truth. Policies differ by campus — **Verify** syllabus language. Facts that matter for grades get a second source (textbook page, paper DOI, official doc).

## SEC-05_WHEN_TO_USE

- You feel slow because the task is **messy**, not because you are “bad.”
- You already have **raw material** (PDF, lecture photo, half draft).
- You will still **rewrite in your voice** after AI helps.

---

## SEC-06_WHEN_NOT_TO_USE

- The assignment forbids AI **or** requires a closed-book exam mimic.
- You are tempted to paste **questions you must solve alone**.
- Uploading materials would leak **privacy** or **copyright** — check first.

## SEC-09_BAD_RESULT_EXAMPLE

## SEC-10_WHY_IT_FAILED

Usually: **skipped verification**, **skipped policy**, **skipped personal rewrite**. Any one collapses marks or trust fast.

---

## SEC-11_GOOD_WORKFLOW

1. Write doubt as one sharp question.
2. Paste **only** allowed excerpts (or describe figure) — not whole book.
3. Ask AI: “Answer using ONLY excerpt; quote lines; else [OUT_OF_TEXT].”
4. If [OUT_OF_TEXT], search textbook index / ask TA.
5. Write final answer in your words + pointer.

---

## SEC-12_COPY_PASTE_PROMPTS

### Prompt A
```txt
Excerpt (paste). My question: ____. Answer using only excerpt. For each sentence, end with (line ref) or mark [OUT_OF_TEXT].
```

### Prompt B
```txt
Compare two interpretations A vs B (I describe). Which is better supported by excerpt? If tie, say [TIE] and what experiment/definition would separate them — homework for me, not invented data.
```

### Prompt C
```txt
Turn answer into 3 bullet **teach-back** — no copying long phrases from excerpt.
```

## SEC-13_GOOD_RESULT_EXAMPLE
