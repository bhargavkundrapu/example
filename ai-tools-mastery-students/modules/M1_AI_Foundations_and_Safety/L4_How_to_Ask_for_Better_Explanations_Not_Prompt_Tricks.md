## SEC-10_WHY_IT_FAILED

Usually: **skipped verification**, **skipped policy**, **skipped personal rewrite**. Any one collapses marks or trust fast.

---

## SEC-11_GOOD_WORKFLOW

1. State your **level** (first exposure / revision / exam depth).
2. Give a **constraint**: max words, must include example, must show steps.
3. Ask for **checks**: “What would a beginner misunderstand?”
4. Teach-back: write the idea in 3 sentences **without** looking.
5. Compare to AI version — fix only your gaps.

---

## SEC-12_COPY_PASTE_PROMPTS

### Prompt A
```txt
Teach me [concept] in 3 layers: (L1) like I am new (2) like I need exam detail (3) one “interviewer follow-up” deep question I should practise answering.
Keep each layer under 120 words.
```

### Prompt B
```txt
Here is my 3-sentence teach-back (paste next). Point out exactly ONE missing link and ONE too-vague word I should define — do not rewrite everything.
```

### Prompt C
```txt
Give me 5 “confusion trap” multiple-choice **stems** only (no answer key). I will solve offline.
```

## SEC-14_PRACTICE_TASK

## SEC-17_COMMON_MISTAKES

1. Asking for “explain everything” — get thin soup.
2. Accepting jargon without asking for a plain alias.
3. Skipping teach-back — the real learning step.
4. Chasing viral prompt threads instead of constraints.
5. Letting AI ask the exam question for you when forbidden.
